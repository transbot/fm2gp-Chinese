# 数学内容与逐行核对

依据中文版第 6.6 节定义 6.11–6.13、定义 6.14 及第 6.7 节书例。以下表格与有限枚举用于核验具体模型；一般证明以任意群和生成元为出发点。

## 来源身份

- 理论为真命题的集合，可由公理和推理规则生成。模型给定集合和理论所需运算，并使理论中的命题成立。整数加法群与模 7 非零余数乘法群均为阿贝尔群理论的模型。3+(−3)=0 与 3×5≡1 (mod 7) 说明各自的逆元与单位元素。
- 自然数到偶自然数的“乘以 2”来自书例，正文明确为**两个加法幺半群之间的同构**。两端都包含 0。映射单射，且每个偶自然数有唯一的自然数原像；f(m+n)=f(m)+f(n)，f(0)=0。定义 6.13 同时关照逆映射保持运算。
- ℤ₄ 与 U(5) 是书中的两个四阶循环群模型，生成元的两种对应产生 f₂、f₃。按 k=0,1,2,3 展示的 b 是**伴读反例**；选择或展开条目与主动将输入设为反例分别处理。
- U(8) 是书中克莱因群的模型。对角线性质是书中的区分命题。下表列出的反证逐行展开其理由。定义 6.14 采用本书的口径，一个一致理论的所有模型彼此同构时称为范畴性的。
- 泛型编程伴读卡使用已经证明不同构的 ℤ₄、U(8)。两者分别提供模 4 加法及单位元素 0、模 8 乘法及单位元素 1；结合律和单位元素足以支持相同的非负整数幂算法。Mod(R ∪ R′) ⊆ Mod(R) 允许相等。/power 的 243 与 15 是其已有整数模型的计算输出。

## 不同构证明

| 稳定步骤 ID | 公式核对 | 前提或依据 |
|---|---|---|
| klein-assume | 假设 φ:ℤ₄→U(8) 是同构 | 同构是双射并保持运算，因而可用单射性 |
| klein-source-sum | φ(2)=φ((1+1) mod 4) | 源群运算 |
| klein-preserve | 等于 (φ(1)×φ(1)) mod 8 | 保持运算；左侧用模 4 加法，右侧用模 8 乘法 |
| klein-square | 等于 1 | U(8) 元素 1、3、5、7 自乘对 8 取余均为 1 |
| klein-identity | 1=φ(0) | 设 u=φ(0)，由保持运算得 u·u=u；群中消去得 u 为目标单位元素 |
| klein-injective | φ(2)=φ(0) 推出 2=0 | 单射性，与 ℤ₄ 中 2≠0 矛盾。∀x, x²=e 对 U(8) 成立，对 ℤ₄ 不成立 |

## 四阶循环群的一般证明

| 稳定步骤 ID | 公式核对 | 前提或依据 |
|---|---|---|
| cyclic4-generator | 任取四阶循环群 G，取生成元 g | 循环性保证存在生成元；由第 6.4 节，g 的阶为 4 |
| cyclic4-bijection | 定义 φ(k)=gᵏ，k=0,1,2,3 | e,g,g²,g³ 中若有重复，则消去得到小于 4 的正返回指数。四个幂互异，且穷尽四元素群，故双射 |
| cyclic4-reduce | φ((k+ℓ) mod 4)=g^((k+ℓ) mod 4)=g^(k+ℓ) | 第一次使用定义，第二次使用 g⁴=e，指数相差 4 的倍数不影响幂 |
| cyclic4-compose | g^(k+ℓ)=gᵏgˡ=φ(k)φ(ℓ) | 同一元素的幂律，参数顺序不变。故为保持运算的双射 |
| cyclic4-categorical | 任取 G₁、G₂。G₁→ℤ₄→G₂ | 第一段是从 ℤ₄ 到 G₁ 的同构的逆映射，第二段是从 ℤ₄ 到 G₂ 的同构；复合仍为同构。故四阶循环群理论具有本书所说的范畴性。放宽为四阶群时至少有上述两个不同构模型 |
