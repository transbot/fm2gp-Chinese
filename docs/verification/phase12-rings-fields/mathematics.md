## 习题 8.6 六行逐项核对

前提：a≠0、b≠0、ab=0；反设 a 可逆。因子顺序始终为 a⁻¹、a、b。

|稳定 ID|公式|本行依据|结论检查|
|---|---|---|---|
|zero-unit-identity|b = 1b|乘法左单位元素|没有引入可交换假设|
|zero-unit-inverse|1b = (a⁻¹a)b|反设 a 可逆，a⁻¹a=1|同一集合中的逆元|
|zero-unit-associate|(a⁻¹a)b = a⁻¹(ab)|乘法结合律|只改变括号，没有交换因子|
|zero-unit-product|a⁻¹(ab) = a⁻¹0|前提 ab=0|替换括号内的整体|
|zero-unit-absorb|a⁻¹0 = 0|定义 8.3 零元吸收性|推出 b=0|
|zero-unit-contradiction|b = 0 ∧ b ≠ 0|与原前提矛盾|否定 a 可逆；解释分别用中文、英文，公式及可访问名称中的数学部分不含语言文字|

六行公式顺序固定，各行依据独立展开。组件测试逐行核对公式、依据及两种语言的可访问名称；浏览器重点展开最后一行并切换语言，检查完整名称与可见解释。真实浏览器在隐藏文本边界插入的空白被明确允许，其他字符使用完整匹配。

## 多项式固定检查点

输入 A=[1,0]、B=[2,0]，标准形为 x 与 2x。

|事件|当前函数 / 刚执行的语句|固定结果|GCD迭代 / 消元|
|---|---|---|---|
|term|remainder / term|T=1/2，Q=0，R=x|0 / 0|
|eliminate|remainder / update|Q=1/2，R=0；x=(2x)×(1/2)+0|0 / 1|
|gcdReturn|gcd / return|最近返回=2x，原始GCD=2x|1 / 1|
|monic|monic / normalize|最近返回=x，原始GCD=2x，首一GCD=x|1 / 1|

首一化后回看前一步，最近返回恢复为 2x；再前进返回 x。原始 GCD 不被首一化覆盖，两步计数相同。预设复用双播放器的应用、暂停、复位、拖动、回看、继续和终点重播流程。英语错误提示明确写出 “the zero polynomial as the divisor”，不将零多项式除式与代数中的 zero divisor 混为一谈。
