## 9.7 加法定义与一个计算

对任意 a,b∈ℕ，(9.1) a+0=a；(9.2) a+s(b)=s(a+b)。定义在第二参数递推。下面是一个输入的计算，行首的等号与上一行相连。

| 稳定ID | 表达式 | 依据 |
|---|---|---|
| sum-first | 2+3 = s(2+2) | 3=s(2)，(9.2) |
| sum-second | = s(s(2+1)) | 在外层s中以2=s(1)应用(9.2) |
| sum-third | = s(s(s(2+0))) | 在最内层以1=s(0)应用(9.2) |
| sum-base | = s(s(s(2))) | 2+0=2，由(9.1) |
| sum-three | = s(s(3)) | 数字名称s(2)=3 |
| sum-four | = s(4) | 数字名称s(3)=4 |
| sum-five | = 5 | 数字名称s(4)=5 |

## 9.7 左单位元素

目标 (9.3) 是定理而非定义。令P(a)表示0+a=a。

| 稳定ID | 表达式 | 依据 |
|---|---|---|
| zero-base | 0+0=0 | 以a=0应用(9.1)，得P(0) |
| zero-hypothesis | 0+k=k | 任取k∈ℕ，暂设P(k)，并未假设全称结论 |
| zero-successor | 0+s(k)=s(0+k) | 以a=0、b=k应用(9.2) |
| zero-replace | = s(k) | 在后继内部用P(k)替换0+k，得P(s(k)) |
| 结论 | ∀a∈ℕ，0+a=a | 满足性质的子集含0且对后继封闭；用第三公理 |

## 9.7 加法结合律

任取并固定a,b∈ℕ，只对c归纳。两次反向使用(9.2)的范围不同。

| 稳定ID | 表达式 | 依据 |
|---|---|---|
| assoc-base | (a+b)+0=a+b | (9.1)，此处第一参数是a+b |
| assoc-base-reverse | = a+(b+0) | 在右参数处反向使用(9.1) |
| assoc-hypothesis | (a+b)+k=a+(b+k) | 任取k∈ℕ，暂设c=k时成立 |
| assoc-successor | (a+b)+s(k)=s((a+b)+k) | 对整个和正向使用(9.2) |
| assoc-substitute | = s(a+(b+k)) | 在s内部使用归纳假设，固定a,b |
| assoc-outer | = a+s(b+k) | **整体反向**使用(9.2)：s(a+(b+k)) → a+s(b+k) |
| assoc-inner | = a+(b+s(k)) | **局部反向**使用(9.2)：仅将右参数s(b+k) → b+s(k)，外层a+…不动 |
| 结论 | (a+b)+c=a+(b+c) | 归纳原理推广到每个c；a,b原本任意 |

相关解释把第6章的半群条件连接到幂算法；没有用交换律来证明结合律，也没有把有限个运行例子当作证明。

## 附录B

| 节 | 前提 → 推导 → 结论 |
|---|---|
| B.1 | 整数n且n²奇；反设n偶，则n=2m，m∈ℤ。n²=2(2m²)，2m²∈ℤ，故n²偶，与保留前提矛盾。n必奇 |
| B.2 起点 | n≥1，从1开始；1=1(1+1)/2 |
| B.2 后继 | 任取k≥1，设前k项和为k(k+1)/2。加上k+1，提取公因子得到(k+1)(k+2)/2，对应n=k+1。由归纳原理成立 |
| B.2 核对 | n=5时两边都是15；这次数值核对不替代证明 |
| B.3 对象 | 十个互异、均小于100的正整数；每个取或不取，共2¹⁰=1024个子集，包括空集 |
| B.3 容器 | 空集和为0，十个最大允许值之和90+…+99=945，故至多有946种和，不保证每个值都出现 |
| B.3 结论 | 1024个子集分入至多946个鸽巢，必有两个不同子集等和；不要求二者不相交 |
