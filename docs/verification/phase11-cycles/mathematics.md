## 源码与空间

- 单循环辅助函数在 ch11.h 的 142–150 行。临时复制发生在 143 行，保存 start 在 144 行；145 行初次求来源、判断及再次求来源，146 行复制，147 行更新 i，149 行写回临时值。j 的作用域限于 for，辅助函数返回 void。[固定源码](https://github.com/transbot/fm2gp-Chinese/blob/24c0da65036056a02cae2cc2848416a5cd9f4b2b/%E9%85%8D%E5%A5%97%E4%BB%A3%E7%A0%81%28fm2gpcode%29/ch11.h#L142-L150)
- 旋转专用的来源变换由 rotate_transform 给出，外层 rotate 根据 gcd 选择起点。演示在任意排列上使用显式逆表和伴读调度。[来源变换](https://github.com/transbot/fm2gp-Chinese/blob/24c0da65036056a02cae2cc2848416a5cd9f4b2b/%E9%85%8D%E5%A5%97%E4%BB%A3%E7%A0%81%28fm2gpcode%29/ch11.h#L153-L165) · [外层调度](https://github.com/transbot/fm2gp-Chinese/blob/24c0da65036056a02cae2cc2848416a5cd9f4b2b/%E9%85%8D%E5%A5%97%E4%BB%A3%E7%A0%81%28fm2gpcode%29/ch11.h#L178-L185)
- 单次辅助函数使用 O(1) 辅助空间。对完整排列做映射、循环分解和访问标记使用 O(n) 辅助空间，执行 O(n) 步。播放器每步保存独立数组、标签和控制状态，每帧 O(n)，完整回放生成与存储均为 O(n²)。复制快照不计入数据传送。
